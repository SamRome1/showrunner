# Code of Conduct

Be kind, be direct, assume good intent. Critique the work, not the person. Harassment of any kind is not tolerated and will result in removal from the project.

Report problems to the maintainer by email listed on the GitHub profile. Reports are handled privately.

This is a condensed statement of the principles in the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies in full.
